# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue for them.

Include what an attacker can do, how to reproduce it, and the version (shown under *Einstellungen → Daten & Sicherung*). You'll get an answer within a week. Fixes go into the latest release; older versions are not patched.

Scope: the app and the Docker image in this repository. Self-hosted installations are run by their operators; please contact them about a specific installation.
